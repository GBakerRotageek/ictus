This project wraps the engine to make multi-step agent pipelines that are
committed, re-runnable and checked before they cost anything. It has spent
several rounds discovering that capabilities it assumed were missing were
already present in the engine and simply unconnected.

Work out what else is in that category. Prefer the concrete and the wirable over
the architectural: a field, a command, a hook, a mode of running. Where you find
something genuinely large, say what it would let a pipeline do that none can do
today, and be honest about which of it the provider we run would actually
honour.
